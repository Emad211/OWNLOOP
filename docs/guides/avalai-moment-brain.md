# AvalAI به‌عنوان مغز لحظه‌های OwnLoop

**وضعیت:** سازگاری ساختاری پیاده‌سازی شده؛ آزمون زنده با کلید واقعی هنوز انجام نشده است.

## تصمیم محصولی

در نسخهٔ فعلی OwnLoop، یک مدل زبانی عنوان، سؤال، گزینه‌ها، روایت کوتاه و تعامل پیشنهادی لحظه‌های مالکیت را تولید می‌کند. AvalAI واسط رسمی دسترسی OwnLoop به مدل‌هاست.

مدل مرجع حقیقت نیست. خروجی مدل فقط یک پیشنهاد است و پیش از نمایش باید از قراردادهای سخت‌گیرانه، حل شناسه‌های شواهد، اعتبارسنجی قطعی، حذف تکرار و رتبه‌بندی عبور کند.

## چرا به معماری تازه نیاز نداریم؟

AvalAI API سازگار با OpenAI ارائه می‌کند و مسیر Responses را با base URL نسخهٔ ۱ پشتیبانی می‌کند. OwnLoop از قبل مرز `responses_json_v1`، درخواست structured JSON، timeout، محدودیت اندازه، retry محدود، عدم ذخیرهٔ پاسخ خام و کلید حافظه‌ای را دارد.

بنابراین این اتصال از همان مسیر موجود استفاده می‌کند:

```text
ورودی کاهش‌یافته و پاک‌سازی‌شده
→ AvalAI /v1/responses
→ Candidate Moment JSON سخت‌گیرانه
→ اعتبارسنجی قطعی شواهد
→ انتخاب محدود
→ لحظهٔ مالکیت
```

هیچ SDK، listener، صف، worker، fallback router یا provider registry تازه‌ای اضافه نمی‌شود.

## endpointهای پشتیبانی‌شده

برای کاربران داخل ایران:

```text
https://api.avalai.ir/v1
```

برای اتصال جهانی یا کاربران خارج از ایران:

```text
https://api.avalai.org/v1
```

OwnLoop مسیر نهایی زیر را از base URL می‌سازد:

```text
https://<avalai-host>/v1/responses
```

مدل hard-code نمی‌شود و باید از تنظیمات محلی انتخاب شود.

## تنظیم در رابط محلی

در بخش تنظیمات محلی:

1. هوش مصنوعی خارجی را فعال کن.
2. یکی از base URLهای AvalAI را وارد کن.
3. شناسهٔ مدل موجود در حساب AvalAI را وارد کن.
4. تنظیمات را ذخیره کن.
5. API key را در کادر کلید وارد و فقط داخل حافظهٔ daemon بارگذاری کن.

کلید در SQLite، artifact، Event، browser storage، URL، log یا diagnostic ذخیره نمی‌شود. پس از راه‌اندازی دوبارهٔ daemon باید دوباره بارگذاری شود.

## نقش LLM

مدل مجاز است:

- از facts و Evidence IDهای موجود، مهم‌ترین لحظه‌ها را پیشنهاد کند؛
- عنوان و متن کوتاه فارسی بسازد؛
- یک سؤال پیش‌بینی یا بررسی طراحی کند؛
- گزینه‌های محدود و غیرقابل‌اجرا پیشنهاد کند؛
- اهمیت و confidence پیشنهادی ارائه کند.

مدل مجاز نیست:

- Evidence ID بسازد یا تغییر دهد؛
- از repository، transcript یا فایل خام بخواند؛
- کد، فرمان، URL، tool call یا callback تولید کند؛
- نتیجهٔ تست، امنیت، صحت یا پوشش را بدون شواهد قطعی اعلام کند؛
- مجوز، اعتماد Hook یا رفتار عامل را کنترل کند.

## وضعیت فارسی

رابط و تجربهٔ نهایی باید فارسی باشند. با این حال، validator قطعی فعلی عمدتاً زبان کنترل‌شدهٔ انگلیسی را می‌شناسد. پشتیبانی محافظه‌کارانه از grammar فارسی باید پیش از ادعای تولید زندهٔ لحظه‌های فارسی تکمیل و با یک Task Run واقعی تأیید شود.

تا آن زمان:

- سازگاری endpoint و محرمانگی کلید پیاده‌سازی شده است؛
- اجرای زندهٔ AvalAI تأیید نشده است؛
- عبور Candidate فارسی از validator تأیید نشده است؛
- هیچ درصدی بر اساس برنامه یا مستندات به‌تنهایی افزایش نمی‌یابد.

## معیار پذیرش اجرای زنده

اتصال فقط زمانی تأییدشده محسوب می‌شود که:

1. یک Task Run واقعی ورودی semantic معتبر بسازد؛
2. AvalAI strict Candidate JSON برگرداند؛
3. raw response و API key در هیچ حالت durable ظاهر نشوند؛
4. Candidateها از validator قطعی عبور کنند؛
5. حداقل یک Moment فارسی انتخاب و در React نمایش داده شود؛
6. شکست API، Replay و Evidence Engine را متوقف نکند.
