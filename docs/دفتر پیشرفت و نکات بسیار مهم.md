## ۱) وعدهٔ مرکزی

OwnLoop داشبورد عامل، log viewer یا گزارش فنی طولانی نیست.

> عامل هوش مصنوعی کد را می‌نویسد؛ انسان باید فهم، تصمیم‌گیری، تشخیص ریسک و مالکیت نگهداری آن را حفظ کند.

مسئلهٔ اصلی این است که کاربر هنگام کار عامل، توجهش را از دست می‌دهد و سراغ کار دیگری می‌رود. OwnLoop باید کار خسته‌کنندهٔ حفظ فهم را به تجربه‌ای کوتاه، جذاب و کم‌اصطکاک تبدیل کند.

چرخهٔ غیرقابل‌مذاکره:

```text
ابهام
→ پیش‌بینی یا انتخاب کاربر
→ آشکارشدن نتیجهٔ واقعی
→ شواهد قطعی
→ واکنش کوتاه
→ ثبت محلی
→ پیشرفت مالکیت انسانی
→ پایان روشن
```

هدف تجربه:

- محدود و بدون پیمایش بی‌پایان؛
- حدود ۶۰ تا ۹۰ ثانیه؛
- فارسی و موبایل‌پسند؛
- جذاب از راه کنجکاوی، کشف، کنترل و پیشرفت؛
- بدون streak، امتیاز جعلی یا طراحی اعتیادآور؛
- بدون معادل‌دانستن کلیک با فهم.

## ۲) زیبایی و حفظ توجه

بازخورد مستقیم کاربر دربارهٔ نمونهٔ مستقل نسخهٔ صفر:

> **«خیلی زشت بود.»**

این یک شکست واقعی UX است و بابت آن درصد محصول بالا نرفته است.

قواعد:

- رابط نباید شبیه dashboard سازمانی یا فرم فنی باشد؛
- چند ثانیهٔ اول باید حس محصول جدی و باکیفیت بدهد؛
- تایپوگرافی فارسی، ریتم، فضای تنفسی و حرکت هدفمند مهم‌اند؛
- هیچ ظاهر تازه‌ای تا آزمون مستقیم کاربر «زیبا» یا «تأییدشده» نیست؛
- پذیرش بصری و اثبات حفظ توجه همچنان **صفر** است.

## ۳) مغز لحظه‌ها: AvalAI + LLM

> LLM مغز پیشنهاد و قاب‌بندی Momentهاست و AvalAI واسط رسمی مدل‌هاست.

### endpointهای رسمی

```text
ایران:  https://api.avalai.ir/v1
جهانی: https://api.avalai.org/v1
مسیر:  /responses
```

LLM مجاز است عنوان، سؤال، گزینه و روایت کوتاه فارسی را از Semantic Input پاک‌سازی‌شده پیشنهاد دهد؛ اما مجاز نیست Evidence ID، نتیجهٔ تست، امنیت، کامل‌بودن یا نبود ریسک را جعل کند.

مرجع حقیقت:

```text
Git + exit code + Evidence Graph + validator قطعی
```

امنیت:

- مدل hard-code نیست؛
- API key فقط در حافظهٔ daemon است؛
- در SQLite، artifact، log، diagnostics، URL یا browser storage ذخیره نمی‌شود؛
- ورودی کلید در UI uncontrolled است و پس از خواندن فوراً پاک می‌شود؛
- certification summary شامل raw request، raw response، متن خطا یا کلید نیست؛
- کلید هرگز نباید در Chat ارسال شود.

- `apps/web/src/attention-session.ts`

- زمان را محافظه‌کارانه ۱۲ ثانیه برای هر Moment برآورد می‌کند؛
- حداکثر زمان پیش‌بینی‌شده ۸۴ ثانیه است؛

- progress و شمارندهٔ پایان فقط همان جلسه را می‌سنجند؛
- follow-up summary همچنان کل projection همان Run را می‌بیند؛
- ranking، endpoint، persistence یا Moment تازه‌ای ساخته نشده است.

### پایداری startup ویندوز

- timeout پیش‌فرض start/stop از ۱۰ به ۳۰ ثانیه افزایش یافت؛
