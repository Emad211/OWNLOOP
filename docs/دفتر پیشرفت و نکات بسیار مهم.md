## ۱) وعدهٔ مرکزی

OwnLoop نباید فقط گزارش، log یا داشبورد عامل برنامه‌نویس باشد.

> عامل هوش مصنوعی کد را می‌نویسد؛ انسان باید فهم، تصمیم‌گیری، تشخیص ریسک و مالکیت نگهداری آن را حفظ کند.

مسئلهٔ اصلی:

- کاربر هنگام کار عامل منتظر نمی‌ماند و سراغ کار دیگری می‌رود؛
- خواندن diff و خروجی فنی خسته‌کننده است؛
- در پایان کد تحویل گرفته می‌شود، اما فهم انسان عقب می‌ماند.

چرخهٔ غیرقابل‌مذاکره:

```text
ابهام
→ پیش‌بینی یا انتخاب کاربر
→ آشکارشدن نتیجهٔ واقعی
→ شواهد قطعی
→ واکنش کوتاه
→ ثبت محلی
→ پیشرفت مالکیت انسانی
→ پایان روشن
```

این تجربه باید محدود، ۶۰ تا ۹۰ ثانیه‌ای، کم‌اصطکاک، موبایل‌پسند و بدون پیمایش بی‌پایان باشد.

## ۲) زیبایی و حفظ توجه

بازخورد کاربر دربارهٔ نمونهٔ مستقل نسخهٔ صفر:

> **«خیلی زشت بود.»**

این یک شکست واقعی تجربهٔ کاربری است؛ بابت آن درصد محصول بالا نرفت.

قواعد:

- رابط نباید شبیه dashboard سازمانی یا فرم فنی باشد؛
- چند ثانیهٔ اول باید حس محصول جدی و باکیفیت بدهد؛
- تایپوگرافی فارسی، ریتم، فضای تنفسی و حرکت هدفمند مهم‌اند؛
- جذابیت باید از کشف، کنترل و پیشرفت بیاید، نه امتیاز جعلی یا اعتیاد؛
- هیچ ظاهر تازه‌ای تا آزمون مستقیم کاربر «تأییدشده» نیست.

پنل AvalAI تازه از نظر ساختار و آزمون خودکار پذیرفته شده است، اما هنوز از نظر زیبایی توسط کاربر ارزیابی نشده است.

## ۳) مغز لحظه‌ها: AvalAI + LLM

تصمیم محصولی:

> LLM مغز پیشنهاد و قاب‌بندی Momentهاست و AvalAI واسط رسمی دسترسی OwnLoop به مدل‌هاست.

### endpointها

```text
ایران:  https://api.avalai.ir/v1
جهانی: https://api.avalai.org/v1
مسیر:  /responses
```

### مرز مسئولیت

LLM مجاز است:

- از Semantic Input کاهش‌یافته و پاک‌سازی‌شده استفاده کند؛
- عنوان، سؤال، گزینه و روایت کوتاه فارسی بسازد؛
- Momentهای مهم را پیشنهاد کند.

LLM مجاز نیست:

- Evidence ID بسازد یا تغییر دهد؛
- نتیجهٔ تست، امنیت، کامل‌بودن یا نبود ریسک را جعل کند؛
- repository، transcript یا فایل خام را مستقیم بخواند؛
- فرمان یا کد اجرایی تولید کند؛
- مرجع حقیقت باشد.

مرجع حقیقت:

```text
Git + exit code + Evidence Graph + validator قطعی
```

### امنیت کلید

- مدل hard-code نیست؛
- API key فقط در حافظهٔ daemon است؛
- در SQLite، artifact، log، diagnostics، URL یا browser storage ذخیره نمی‌شود؛
- ورودی کلید در پنل AvalAI uncontrolled است، مستقیم خوانده و بلافاصله پاک می‌شود؛
- کلید هرگز نباید در Chat ارسال شود.

### تصمیم زبان

- عنوان، سؤال و گزینه‌های قابل‌دیدن فارسی‌اند؛
- `claim` داخلی فعلاً کوتاه و کنترل‌شده است؛
- validator فقط facts و Evidence IDهای واقعی را می‌پذیرد؛
- متن نمایشی مدل در UI مرجع حقیقت نیست.
